  in 30s"}

    4. features.apply_preprocessing(X, MODEL_LOADER.preprocessor,               
  feature_names)                                                                
    5. prob = MODEL_LOADER.model.predict_proba(X)[0][1]                         
    6. risk = features.classify_risk(prob)                                      
    7. threshold = float(os.environ.get("MODEL_THRESHOLD", "0.35"))             
    8. prediction = 1 if prob >= threshold else 0                               
    9. latency_ms = (time.time() - start) * 1000

    13. Return FraudPredictionResponse

● Created services/fraud-model-api/app/main.py. A few implementation notes:

  - 503 on unloaded model: returns JSONResponse directly (not HTTPException) so
  the body is exactly {"error": "Model not loaded, retry in 30s"} —
  HTTPException would wrap it under "detail"
  - Middleware order: CORS via add_middleware runs outermost (handles OPTIONS
  preflight before any logic); request logging via @app.middleware("http") runs
  inside it, so it sees post-CORS requests only
  - Redis failures are non-fatal: cache write errors increment REDIS_ERRORS and
  log a warning but don't fail the prediction
  - /model/reload guard: rejects if RELOAD_SECRET is empty string (not
  configured) OR if the header doesn't match — prevents accidental open reload
  endpoint in dev
  - X-Reload-Key header: FastAPI auto-maps the x_reload_key parameter name to
  the X-Reload-Key HTTP header
